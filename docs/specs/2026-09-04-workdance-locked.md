# WorkDance 锁定规格

- 日期：2026-09-04
- 状态：三钉已用默认拍板。机制冻结。界面稿由 Lumen 出，代码等规格进仓后从 WP0 开。
- 仓库：https://github.com/DavidDeng9896/workdance
- 依据：极简核心 PRD；Archon brief；Lumen UX；Javis WP0–WP5。

## 0. 一句话

手势只操作，语音只录入，指哪说哪。普通本 RGB 摄像头 + 麦克风，本地 MediaPipe Hands + 离线 ASR，Win/Mac，不上传音视频。

## 1. 三钉（2026-09-04 默认）

| 钉 | 定案 |
| --- | --- |
| 摄像头 | **内置前置**为兼容主路径；校准按自拍平面做。俯拍外置为后续增强，不挡第一刀。 |
| 术语词表 | 第一刀 **中文听写**，不做实验术语热词表。热词/自定义词表放后续。 |
| 主攻软件 | 第一刀 **浏览器**（坐标点击为主；AX/UIA 命中为增强）。Word / 仪器桌面软件不进第一刀验收。 |

## 2. 状态

- 休眠（默认）：3–5FPS 只侦掌，无光标、无精细手势。
- 手势激活：掌入镜稳定 ≥0.5s → 25–30FPS，出虚拟光标。
- 录音中（用户可见第三态）：G07 长握录音期间。
- 离镜 / 无操作 1.2s → 回落休眠。
- 全局可关手势，仅留语音兜底。

掌置信度 < 0.6 不视为有效掌。

## 3. 手势（P0）

| ID | 动作 | 作用 |
| --- | --- | --- |
| G01 | 掌对镜停留 0.5s | 唤醒 |
| G02 | 张掌平移 | 移光标 |
| G03 | 短促握拳 | 单击；持续 >300ms 不当单击 |
| G04 | 握拳平移 | 滚页面 |
| G05 | 掌下挥 | 返回 / 关弹窗 |
| G06 | 手离镜 | 倒计时回落 |
| G07 | 长握 ≥1s | 录音，最长 60s；手离镜立刻停；松拳 → ASR → **追加**写入当前焦点 |
| G08 | 快捷手势 2 | 停录并落带时间戳的 MD 备忘（不存原音频） |

不做：手势手写、精细框选、复杂拖拽、空中键盘。

执行：**A 路径坐标注入为主**（Win SendInput / Mac CGEvent）。无障碍 Press/SetValue 为增强；浏览器默认坐标点击。

焦点：悬停输入框/控件 0.4s 锁焦点；握拳可二次确认。手势移动不解除已锁焦点、不中断语音。第三方控件拿不到时降级键盘 Unicode 注入。

## 4. 双模型与离线

- 视觉：MediaPipe Hands（本机）。双档帧率见 §2。
- 语音：离线 ASR，中文听写。不上传音频；备忘只存 MD。
- Rust 分线程跑视觉与 ASR；系统注入串行。
- 拔网线仍可手势 + 听写。

## 5. 工作包

WP0 壳（托盘/权限/校准）→ WP1 双档视觉 → WP2 G02–G05 → WP3 焦点+G07 → WP4 G08 备忘 → WP5 托盘三态/设置/仅语音。

验收：开局无误触光标；指哪说哪（浏览器）；离线；Win/Mac 各一条主路径。

## 6. 明确不做（v1）

云 VLM 看屏、深度/红外硬件、俯拍为唯一路径、术语热词、Word/仪器专项适配、画线/手写。
